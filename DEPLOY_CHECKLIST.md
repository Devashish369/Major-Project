## A. Database – Neon

1. [ ] Go to **neon.tech** → *Sign up / Log in* → **New Project**. Name `intellipm`, region closest to the demo (e.g. *AWS Asia Pacific (Singapore)* or *Mumbai* if offered). Postgres version: default.
2. [ ] On the project dashboard click **Connect** → choose the default branch and database `neondb` → copy the **connection string**. It looks like
   `postgresql://<user>:<password>@ep-xxxx.<region>.aws.neon.tech/neondb?sslmode=require&channel_binding=require`.
   Keep it in a password manager; it contains the database password.
3. [ ] Verify: in Neon's **SQL Editor** run `select 1;` → returns `1`.

## B. Code

4. [ ] On your PC: `git status` is clean and `git log origin/main..main` is empty (everything pushed to `Devashish369/Major-Project`, branch `main`).

## C. Render – Blueprint (backend + frontend)

5. [ ] **dashboard.render.com** → *New +* → **Blueprint** → *Connect GitHub* (approve access to `Devashish369/Major-Project` only) → select the repo, branch `main`. Render reads `render.yaml` and lists `intellipm-api` (web service) and `intellipm-web` (static site).
6. [ ] Fill in the prompted values (exact names):

   | Service | Variable | Value |
   |---|---|---|
   | intellipm-api | `DATABASE_URL` | the Neon string from step 2 |
   | intellipm-api | `LLM_API_KEY` | your Groq key |
   | intellipm-api | `LLM_FALLBACK_API_KEY` | your Gemini key (optional – leave empty to skip) |
   | intellipm-api | `CORS_ORIGINS` | `https://intellipm-web.onrender.com` (no trailing slash; fix in step 9 if Render picks another name) |
   | intellipm-web | `VITE_API_BASE_URL` | `https://intellipm-api.onrender.com/api/v1` (fix in step 9 if different) |

   `SECRET_KEY` is generated by Render; `PYTHON_VERSION=3.13.13`, `NODE_VERSION=22`, the LLM URLs/models and `USE_CACHED_PLAN_ONLY=false` come from `render.yaml`.
7. [ ] Click **Apply**. Wait until both services show **Live** (first backend build ≈ 5–10 min).
   - If the backend build says Python 3.13.13 is unavailable: *intellipm-api → Environment* → set `PYTHON_VERSION` to the newest offered `3.13.x` → *Save, rebuild and deploy*.
8. [ ] **Verify the API**: open `https://<intellipm-api URL>/api/v1/health` → `{"success":true,"data":{"status":"ok"},...}`. (First request after idle can take 30–60 s.)
9. [ ] **Check the two URLs match**: copy the real URLs from each service page. If they differ from step 6, edit `CORS_ORIGINS` (intellipm-api → Environment) and `VITE_API_BASE_URL` (intellipm-web → Environment), then **Manual Deploy → Deploy latest commit** on *both*.

## Speed and cost – things only you can do on the dashboards

The code is already optimised (see README "Speed"). These settings decide the rest:

- [ ] **Measure the API↔database distance** after the deploy: open `https://intellipm-api.onrender.com/api/v1/health/db`.
  `db_round_trip_ms` of about **1–5** means Render and Neon are in the same region: nothing to do.
  **30 or more** means they are in different regions (Render's default is Oregon, your Neon project is
  *AWS US East 2, Ohio*), and every request pays that 4–6 times. A region can never be changed in place;
  the easier fix is on the Neon side:
  1. Neon → New project → region **AWS US West 2 (Oregon)** (if Render shows Oregon) → copy the connection string.
  2. Render → `intellipm-api` → Environment → replace `DATABASE_URL` → Save (it redeploys).
  3. From your PC, seed the new database (section D, with `DEMO_PASSWORD` set). Accounts created on the old
     database are not copied; register them again (or keep the old one if they matter).
  4. Open `/api/v1/health/db` again: it should now be a few ms. Delete the old Neon project afterwards.
- [ ] **Keep-awake is automatic**: `.github/workflows/keep-awake.yml` pings `/api/v1/health` every 10 minutes
  from 06:30 to 00:30 IST (GitHub → Actions tab shows the runs; "Run workflow" pings once by hand). It is free
  for this public repository, uses about 560 of Render's 750 free hours, and does not touch the database.
  GitHub pauses scheduled jobs after 60 days without a commit – re-enable it in the Actions tab if so.
- [ ] **Neon wakes in about a second** after 5 idle minutes; the very first request after a quiet spell is therefore a little slower. Open the site once before presenting.
- [ ] **Billing**: never add a payment method to Render, keep `plan: free`, never upgrade Neon or enable billing on the Gemini key's Google project. Details: `docs/FREE_TIER.md`.
